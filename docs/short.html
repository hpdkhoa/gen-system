gen-system, in one page

A Go engine that parses your code, writes down the facts it found about every routine, lets you correct them, and keeps only generated code that compiles. Two local models, one 16 GB GPU, offline.

What it does, in order

  • Understand. Parses the code into an AST, symbol index, call graph and control flow graph. No model. Six parsers: Go, COBOL with copybooks, CA Gen, Java, TypeScript, Python.
  • List. For each routine it lists the inputs, the calls, the data it writes and the action its name suggests. It calls each line a belief. A local model may add claims. The parser checks each claim. A claim the parser contradicts gets a mark and never steers anything.
  • Correct. You fix any belief. Only beliefs a person verified steer generation. If the code changes under your fix, you see both values.
  • Generate. A planner model picks entities and operations. A coder model writes one operation at a time, with context from the graph, not from text chunks.
  • Gate. Each operation must compile alone. Two repairs, then the gate replaces it with an explicit not implemented stub and counts it. Then vet, build, test. Then the parser rereads the result.
  • Repeat. Temperature 0, seed 42. A suite runs the same prompt N times and reports how many outputs differed.

What it is not

  • Not a chat assistant. No autocomplete.
  • Not Aider, Cursor or Copilot, and not measured against them.
  • Not "always correct". It refuses to hide which parts it could not prove.

Limits

  • 44.4% of generated operations end as stubs with the production models.
  • The suite measures generation determinism; nobody promises it. The parser is deterministic, and its tests prove it.
  • The Python parser shells out to python3. The other five are pure Go.
  • The Java parser does not model lambdas yet, and says so in the node it emits.

Run it

git clone https://github.com/hpdkhoa/gen-system.git && cd gen-system
./install.sh                          # Go, Ollama, the two models
understand-server --root ./your-repo  # read a codebase, correct beliefs in the Studio
gen idea --out ./app "a library lending service with members, books and loans"

./install.sh --understand installs the read only half with no model, for an air gapped review.

Remember it as

It writes its assumptions down and checks the model against the parser. You can correct any line, and it ships only code that compiled.
