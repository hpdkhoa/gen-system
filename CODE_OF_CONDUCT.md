# Code of conduct

gen-system is a small project. This page sets the rules for the issues, pull requests,
discussions and any other place where people talk about it.

## The rules

- Be respectful. Criticize code and ideas, not people.
- Assume the other person means well. Many contributors write English as a second language,
  me included. Ask when something is unclear.
- Keep it on topic. Talk about gen-system, the code it reads and the code it writes.
- No harassment of any kind: insults, slurs, sexual language or images, threats, personal attacks,
  or posting someone's private information.
- No spam and no advertising.

## What happens when someone breaks them

I am the maintainer and I enforce these rules. Depending on what happened, I may:

1. ask the person to stop or to edit what they wrote;
2. hide or delete comments, issues or pull requests;
3. lock a thread;
4. block the person from the repository, for a while or for good.

Harassment and threats lead straight to a block.

## Report a problem

Email contact@500kv.co. Say what happened, where, and add links or screenshots. I read every
report, keep the reporter's name private, and reply within a week.

If the report is about me, you can also report the account to GitHub through
[GitHub's reporting page](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

## Scope

These rules apply in every gen-system space, and anywhere someone represents the project in
public.
